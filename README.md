# Panggung Suara: Lab Bernyanyi

Lab Maya Seni Musik untuk murid SD. Bersama Nuri si burung nuri, murid bereksperimen di lab suara: menebak, mencoba alat, menyimpulkan, lalu menguji. Lima percobaannya membahas napas dan sikap tubuh, tinggi-rendah nada, ketukan dan tempo, serta keras-lembut suara. Di akhir, murid menyanyikan lagu daerah "Gundul-Gundul Pacul" bersama teman.

Mainkan: https://panggungsuara.klikajar.com/

## Yang ada di versi 4
- **Layar Suara**: gelombang bunyi asli tampil langsung. Nada tinggi membuat gelombang rapat, suara keras membuat gelombang tinggi.
- **Jurnal Lab**: tebakan, hasil percobaan, dan temuan murid. **Catatan Guru** menampilkan bintang dan tebakan awal tanpa data pribadi.
- **Mikrofon pilihan**: suara murid hanya ditampilkan langsung, tidak direkam dan tidak disimpan.
